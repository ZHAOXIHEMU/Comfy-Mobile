# 任务与界面架构

Android MainActivity 仅承载本地 WebView 和受限桥接；NativeBatchService、BatchEngine、BatchStore 负责网络重试、持久化、上传和结果缓存。实际整批调度由电脑 BatchManager 承担，手机离开前台或进程重启不决定电脑是否继续出图。

电脑扩展接收完整计划，使用批次 ID 做幂等处理，确定性 prompt ID 恢复已提交任务，逐张持久化完成计数与输出。App 轮询恢复所有未收取结果。暂停等待当前已提交图片完成后停在下一张之前；继续显式发送。取消整批剩余任务，只操作本批次拥有的 prompt。

手机运行按钮保持绿色；左向右滑到底取消（红），右向左滑到底暂停（黄），已滑过部分实色，短渐变跟随手指，松手确认完整行程。

主页面使用同一条连续轨道，轻拖／明确快速横划可切页，区分横纵方向，保留系统边缘返回与子控件手势。大图在 1× 使用连续横向滚动；双指缩放后单指平移，缩回 1× 后恢复换图；上滑显示信息时锁定横向换图。

生成结果、图库和大图增量复用已有图片元素，收到新结果不重载当前图片。App 启动／真正从后台返回时异步预读 MediaStore 索引，内部进入选图页复用进程缓存及首屏缩略图；权限变化与手动刷新例外。
